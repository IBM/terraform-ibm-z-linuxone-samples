HAProxy — Install & Configure

Target host: tfe-s390x.dev.fyre.ibm.com  ·  Architecture: s390x (IBM Z)  ·  Purpose: Load balancer for Terraform Enterprise (active-active)

OVERVIEW Traffic Architecture

Client (HTTPS :443 / HTTP :80) │ ▼ ┌─────────────────────────────────┐ │ HAProxy tfe-s390x:443 / :80 │ ← this guide │ TCP passthrough (mode tcp) │ └─────────────────┬───────────────┘ │ ┌─────────┴──────────┐ ▼ ▼ TFE container :443 (tfe02 — future) 127.0.0.1:443 │ ▼ TFE handles TLS termination
HAProxy uses TCP passthrough — it does not terminate TLS. TFE handles its own certificates. No certs are needed on HAProxy.

STEP 1 Install HAProxy

RHEL / CentOS / Fedora (dnf)

dnf install -y haproxy

Verify installation

haproxy -v

Enable and start the service

systemctl enable haproxy
systemctl start haproxy
systemctl status haproxy

STEP 2 Back Up the Default Config

cp /etc/haproxy/haproxy.cfg /etc/haproxy/haproxy.cfg.bak
Always keep a backup before modifying. Restore with: cp /etc/haproxy/haproxy.cfg.bak /etc/haproxy/haproxy.cfg

STEP 3 Configure HAProxy for TFE

Edit /etc/haproxy/haproxy.cfg and add the TFE sections. The key additions are highlighted below.

Full configuration file

#---------------------------------------------------------------------
# Global settings
#---------------------------------------------------------------------
global
    log         127.0.0.1 local2
    chroot      /var/lib/haproxy
    pidfile     /var/run/haproxy.pid
    maxconn     4000
    user        haproxy
    group       haproxy
    daemon
    stats socket /var/lib/haproxy/stats
    ssl-default-bind-ciphers PROFILE=SYSTEM
    ssl-default-server-ciphers PROFILE=SYSTEM

#---------------------------------------------------------------------
# Defaults
#---------------------------------------------------------------------
defaults
    mode                    http
    log                     global
    option                  httplog
    option                  dontlognull
    option http-server-close
    option forwardfor       except 127.0.0.0/8
    option                  redispatch
    retries                 3
    timeout http-request    10s
    timeout queue           1m
    timeout connect         10s
    timeout client          1m
    timeout server          1m
    timeout http-keep-alive 10s
    timeout check           10s
    maxconn                 3000

#---------------------------------------------------------------------
# TFE — HTTP frontend (redirect to HTTPS)
#---------------------------------------------------------------------
frontend tfe_http
    bind *:80
    mode http
    redirect scheme https code 301

#---------------------------------------------------------------------
# TFE — HTTPS frontend (TCP passthrough)
#---------------------------------------------------------------------
frontend tfe_https
    bind *:443
    mode tcp
    option tcplog
    default_backend tfe_nodes

#---------------------------------------------------------------------
# TFE — backend nodes
#---------------------------------------------------------------------
backend tfe_nodes
    mode tcp
    balance roundrobin
    option tcp-check

    # tfe01 — active node (same host as HAProxy)
    server tfe01 127.0.0.1:443 check

    # tfe02 — uncomment when second node is ready
    # server tfe02 <TFE02_IP>:443 check

#---------------------------------------------------------------------
# HAProxy stats page
# Access: http://tfe-s390x.dev.fyre.ibm.com:8404/stats
#---------------------------------------------------------------------
listen stats
    bind *:8404
    mode http
    stats enable
    stats uri /stats
    stats refresh 10s
Note on mode tcp vs http: The defaults block sets mode http. The TFE frontend and backend explicitly declare mode tcp to override this — required for TLS passthrough.

STEP 4 Validate and Restart HAProxy

Check configuration syntax

haproxy -c -f /etc/haproxy/haproxy.cfg

Expected output: Configuration file is valid

Restart HAProxy

systemctl restart haproxy
systemctl status haproxy

Confirm HAProxy is listening on all expected ports

ss -tlnp | grep haproxy

Expected output:

LISTEN  0  3000  0.0.0.0:80    0.0.0.0:*  users:(("haproxy",...))
LISTEN  0  3000  0.0.0.0:443   0.0.0.0:*  users:(("haproxy",...))
LISTEN  0  3000  0.0.0.0:8404  0.0.0.0:*  users:(("haproxy",...))
LISTEN  0  3000  0.0.0.0:5000  0.0.0.0:*  users:(("haproxy",...))

STEP 5 Open Firewall Ports

Open required ports

firewall-cmd --permanent --add-service=http      # port 80
firewall-cmd --permanent --add-service=https     # port 443
firewall-cmd --permanent --add-port=8404/tcp     # stats page
firewall-cmd --reload

Verify open ports

firewall-cmd --list-ports
firewall-cmd --list-services

STEP 7 Adding tfe02 Later (active-active)

When the second TFE node is ready, add it to the backend in /etc/haproxy/haproxy.cfg:

backend tfe_nodes
    mode tcp
    balance roundrobin
    option tcp-check

    server tfe01 127.0.0.1:443 check
    server tfe02 <TFE02_IP>:443 check   # ← add this line

Then reload HAProxy without dropping existing connections:

haproxy -c -f /etc/haproxy/haproxy.cfg   # validate first
systemctl reload haproxy                  # graceful reload
